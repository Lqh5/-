# 一箭又一箭（Arrow Out）

一款使用 **Python + Pygame** 开发的点击式箭头解谜小游戏。参考微信小游戏《一箭又一箭》的核心玩法，独立实现全部代码与关卡。

玩家需要观察棋盘上箭头的方向与相互阻挡关系，按合适顺序点击箭头，让所有箭头依次飞出棋盘。

## 游戏简介



* 棋盘中包含朝上、下、左、右四个方向的箭头；

* 点击箭头：若其前进方向到棋盘边界之间没有其他箭头阻挡，箭头飞出并消失；

* 若路径上有其他箭头阻挡，箭头不消失，并以**红色高亮 + 抖动**提示碰撞，同时**消耗 1 次失误机会**；

* 消除本关全部箭头后通关并进入下一关；

* 失误次数耗尽则本关失败，可重新开始；

* 共 **3 个难度递增的关卡**（4 / 6 / 8 个箭头），**每局开始都随机生成新布局**，且生成器从算法上保证每局都有解。

## 开发环境



* Python 3.13（Windows 11）

* pygame 2.6.1

* 其他依赖：仅 Python 标准库

## 安装和运行方法



```

python -m venv venv

venv\Scripts\activate

\# 2. 安装依赖

pip install pygame

\# 3. 运行游戏

python game.py

\# 4. 运行自动化测试（核心逻辑）

python test\_logic.py

\# 5. 生成各界面截图（可选）

python demo\_shots.py

\# 6. 生成自动通关演示 GIF（可选）

python demo\_gif.py
```

> 提示：Python 3.14 暂无 pygame 预编译包（会触发源码编译并下载 SDL 依赖，容易超时），建议使用 Python 3.13。

## 游戏操作说明



| 操作           | 说明          |
| ------------ | ----------- |
| 鼠标点击箭头       | 尝试让箭头飞出     |
| 点击「重新开始」按钮   | 当前关卡重置为初始状态 |
| 点击「开始游戏」     | 从第 1 关开始    |
| 通关后点击「进入下一关」 | 进入下一关       |

**通关技巧**：优先点击能直接飞出的箭头；被阻挡的箭头会消耗失误次数，先消除阻挡它的箭头再点击。

## 实现思路（简述）



* **关卡生成**：关卡不写死，每次开局调用 `random_grid(箭头数)` 随机生成；采用"反推法"保证可解——从空棋盘逐个放箭头，要求新箭头自身前方无任何已放箭头，于是按放置倒序消除一定通关；同时优先让新箭头挡住旧箭头，制造解谜依赖；
* **方向表示**：0 = 上、1 = 右、2 = 下、3 = 左，映射为行 / 列增量 `(-1,0)(0,1)(1,0)(0,-1)`；
* **路径检测**：`path_clear(r, c)` 沿箭头方向逐格前进，直到棋盘边界或遇到箭头；遇到箭头返回 `False`（被阻挡），到达边界返回 `True`；
* **可解性验证**：`solve_level()` 是 DFS 回溯求解器，启动时对随机生成器做 60 次抽检，确认每关配置产出的棋盘全部可解后才进入游戏。
